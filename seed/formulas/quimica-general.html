🧪 Química General

Fórmulas esenciales · Química

Estequiometría

Moles n = masa / masa molar
N° Avogadro n = N / NA   (NA = 6.022×10²³)

Gases

Ideal PV = nRT   (R = 0.08206 L·atm/mol·K)
Combinada P₁V₁ / T₁ = P₂V₂ / T₂

pH y Equilibrio

pH = −log[H⁺]    pOH = −log[OH⁻]    pH + pOH = 14
Constante acidez Ka = [H⁺][A⁻] / [HA]

Termodinámica

Gibbs ΔG = ΔH − TΔS
Equilibrio ΔG° = −RT · ln K
Calor q = m · c · ΔT
