Fórmulas esenciales · Matemática

Derivadas Básicas

d/dx c = 0 (constante)
d/dx xⁿ = n · xn−1 (potencia)
d/dx ex = ex (exponencial)
d/dx ln x = 1/x (logaritmo)
d/dx sin x = cos x (trigonométrica)
d/dx cos x = −sin x (trigonométrica)

Reglas de Derivación

Producto (f · g)' = f' · g + f · g'
Cociente (f/g)' = (f' · g − f · g') / g²
Cadena (f ∘ g)' = f'(g) · g'
